This document describes a vocabulary, in this case ODALA Air & Water - Water (Vocabulary). A vocabulary is a collection of reusable terms, namely classes and properties, whose meaning is recorded through a label and definition. For terms defined in this domain, additional formal agreements are available. For external terms, the formal agreements are copied from the external source.

Summary

The ODALA Air & Water - Water Quality vocabulary provides terminology to describe Water Quality Observations.

Basic terms to describe Observations were reused from the ODALA Air & Water - Core vocabulary, but for Water Quality several new terms were added. Each term describes a particular type of Observation of the quality of water.

To exchange data about the concentration of harmful or indesirable substances an instance of the class ChemicalAgentConcentration can be used.

For the biological quality of water use the classes BioIndicatorObservation and BioticIndexObservation: the first to describe observations of living organisms acting as a bioindicator, the second to aggregate counts of vulnerable organisms into an index.

More generic Water Quality Observations should be described with the terms in the ODALA Air & Water - Core vocabulary.

A class WaterFeature is provided to communicate which real-world Object is actually being observed or sampled. It can be substituted with any instance of a class in the domain of water or typed by means of a codelist.

2. Conformity

An exchange of data, by whatever means, is subject to this vocabulary when it uses the terminology (classes and properties) in a manner consistent with the semantics established in the latest version of the specification (domain, scope, definition and usage) and does not use terminology from other vocabularies as an alternative to the proposed terminology included in this vocabulary.

4. Classes

This section provides a formal definition to each class.

Class BioIndicatorObservation

Type Class
URI https://purl.eu/ns/air-and-water/water#BioIndicatorObservation
Specialization of
  • http://def.isotc211.org/iso19156/2011/Observation#OM_Observation
Definition Observation that assesses the biological Quality of Water based on the overall condition of indicator species.

Usage

 These species, also called BioIndicators, are living organisms such as plants, planktons, animals, microbes etc. More specifically, biochemical, physiological, behavioural or population changes are monitored.

Status

 https://data.vlaanderen.be/doc/concept/StandaardStatus/KandidaatStandaard

Class BioticIndexObservation

Type Class
URI https://purl.eu/ns/air-and-water/water#BioticIndexObservation
Specialization of
  • https://def.isotc211.org/iso19156/2011/Observation#Measurement
  • http://def.isotc211.org/iso19156/2011/Observation#OM_Observation
Definition Observation that assesses the biological Quality of Water on a certain scale based on what organisms are present in the Water and in what quantities.

Usage

 In practice this comes down to counting specimens of certain species of macro-invertebrates like worms, snails, flies, clams etc present in the Water, weighted by the extent to which they tolerate Water pollution and combined into a single WaterqQuality score.

Status

 https://data.vlaanderen.be/doc/concept/StandaardStatus/KandidaatStandaard

Class ChemicalAgentConcentrationObservation

Type Class
URI https://purl.eu/ns/air-and-water/water#ChemicalAgentConcentrationObservation
Specialization of
  • https://def.isotc211.org/iso19156/2011/Observation#Measurement
  • http://def.isotc211.org/iso19156/2011/Observation#OM_Observation
Definition Observation to assess the chemical Quality of Water by estimating the concentration of a harmful or unsuitable substance.

Usage

 Actually the Measurement of the amount of the substance in the Water, usually over some averaging period. Result is how much of the substance is found eg in milligrams-per-liter.

Status

 https://data.vlaanderen.be/doc/concept/StandaardStatus/KandidaatStandaard

Class WaterFeature

Type Class
URI https://purl.eu/ns/air-and-water/water#WaterFeature
Specialization of
  • https://def.isotc211.org/iso19156/2011/GeneralFeatureInstance#GFI_Feature
Definition Real-world Object related to Water.

Usage

 It is the featureOfInterest, the Object of which some property is observed to assess WaterQuality. This can be for example a waterbody like the Canal Brussels-Charleroi. The Waterfeature can be typed via the "type" attribute (value would be "waterbody-canal" for example), but substitution by a typed instance (eg an instance of type "Canal", subclass of a class "Waterbody") is also allowed. In either case, the observedProperty must be a phenomenon related to the WaterFeature type. If the WaterFeature is not observed directly, but rather indirectly by sampling it, the WaterFeature is the sampledObject and the sample assumes the role of featureOfInterest.

Status

 https://data.vlaanderen.be/doc/concept/StandaardStatus/KandidaatStandaard

Class WaterQualityObservationCollection

Type Class
URI https://purl.eu/ns/air-and-water/water#WaterQualityObservationCollection
Specialization of
  • https://www.w3.org/TR/vocab-ssn-ext/#sosa:ObservationCollection
Definition A Collection of one or more WaterQualityObservations,whose members share a common value for one or more properties.

Status

 https://data.vlaanderen.be/doc/concept/StandaardStatus/KandidaatStandaard

Class WaterQualityParameterObservation

Type Class
URI https://purl.eu/ns/air-and-water/water#WaterQualityParameterObservation
Specialization of
  • https://def.isotc211.org/iso19156/2011/Observation#Measurement
  • http://def.isotc211.org/iso19156/2011/Observation#OM_Observation
Definition Observation to assess physical Quality of Water by measuring certain physical quantities.

Usage

 These quantities are parameters like temperature, salinity, turbidity, suspended/disolved solids etc.

Status

 https://data.vlaanderen.be/doc/concept/StandaardStatus/KandidaatStandaard

6. External terminology

Since 2025, external terms are no longer included as non-normative mapping in vocabularies of data.vlaanderen.be.

Instead, a table with which external URIs are used has been added to each application profile. This simplifies the objective of this document. Namely listing and managing terms defined in this namespace.

To still achieve harmonization of the use of external terminology, a general mapping is published.
